# CS3 — IMDb Review Sentiment by Genre

## Repository purpose
This repository contains all materials needed to complete a Case Study to determine how Trump's social media posts about tariffs affect the S&P500. It is designed so a student can quickly locate the documents, download the required data, run the notebook, and reproduce the main results.

---

## What’s in this repository
- **README.md** — orientation + setup + how to run
- **Hook Document.pdf** — one-page introduction and scenario of the Case Study
- **Rubric.pdf** — success criteria
- **Data** — where to get datasets + how to process them
- **Scripts** — code used to run the case study
- **Supplemental_Materials** — two supporting references (a WSJ article on the topic + a techinal piece on a financial formula)

## How to run
1. Read **`Data/Data Appendix.md`** and download the required datasets.
2. Open the notebook:
   - **`Trump_Tariff_Announcements_and_S&P500.ipynb`**
3. Confirm dataset file paths inside the notebook match your environment.
4. Run all cells top-to-bottom.
